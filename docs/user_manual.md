## 第一步：账号注册与一键登录

万跑跑团助手提供 **微信小程序** 与 **Web 网页端** 双端互通体验：

### 1. 微信小程序端（日常打卡、动态交流推荐）
1. 在微信中搜索小程序 **「万跑跑团助手」**（或直接扫描跑团队长/队友分享的跑团海报、活动小程序码）。
2. 进入后点击底部导航栏最右侧的 **【我的】**。
3. 点击顶部的 **【🟢 微信一键快速登录】** 按钮，完成微信授权一键登录。
4. 登录成功后，顶部将展示您的头像与跑者卡片。您可以点击卡片修改个人昵称或更换专属头像。

### 2. Web 网页管理端（深度数据分析、大屏看板推荐）
1. 使用电脑浏览器访问：`https://rgm.vanpower.net`
2. 进入登录页面，支持微信扫码直接登入，或使用账号密码登入。
3. 登入后自动与您的小程序端数据毫秒级实时同步。

## 第二步：绑定手表与导入运动历史

系统内置与国际知名运动穿戴设备（Garmin 佳明、COROS 高驰）的官方数据直连通道，绑定后每次跑步无需手动上传，跑步数据将在手表保存后 1-3 分钟内自动同步生成训练报告与跑后战报。

### 绑定步骤：
1. 打开 **【我的】** 页面，切换至 **【👤 个人资料与账号】** 标签页。
2. 向下滚动至 **【运动手表数据直连】** 卡片。
3. **绑定 Garmin（佳明）**：
   - 点击 **【绑定佳明账号】**。
   - **选择服务器分区**：国内购买的手表请选择 **“中国区 (garmin.cn)”**；海外版账号请选择 **“国际区 (garmin.com)”**。
   - 输入您在 Garmin Connect App 中使用的**登录邮箱**和**密码**，点击确认。
   - *（提示：密码采用 RSA/AES 加密传输，仅用于建立官方数据同步会话）*。
   - 绑定成功后，系统会自动抓取您最近的跑步活动，并开启日常自动同步。
4. **绑定 COROS（高驰）**：
   - 点击 **【绑定高驰账号】**。
   - 输入高驰 App 绑定的手机号/邮箱与登录密码，点击确认即可。
5. **一键导入个人最佳成绩 (PB)**：
   - 切换到 **【🏃 训练档案与赛事】** 标签页，在“个人最佳成绩 (PB)”卡片右上角点击 **【⚡ 从 Garmin 一键导入】**，系统将自动读取佳明记录中的 5K/10K/半马/全马最快历史完赛时间。

## 第三步：加入“复旦戈”大群与实名资料填写规范

“复旦戈”是复旦大学 EMBA/MBA/经院等商学院戈友与校友跑者的顶级跑步社群。为保障全体队员在备战戈壁挑战赛、跨省校友选拔拉练以及官方赛事中的身份合法性、商业人身意外保险投保以及集训分组安全，大群实行严格的**“2周实名核验准入制”**。

### 3.1 “2周准入核验制”规则说明
> [!IMPORTANT]
> **2周核心准入铁律**：
> 1. 加入大群后，系统将开启 **14 天（2周）临时访问期倒计时**。
> 2. 队员必须在 14 天内，**补齐全部标有 `*` 的必填资料**，并由复旦戈大群管理员审核转正。
> 3. **逾期未完成惩罚**：超期未补齐或未获确认的队员，系统将**自动冻结暂停访问该大群以及该大群从属的一切下级跑团（如：复旦戈闵文跑团、戈友先锋分团等）的全部权限**！您将无法浏览看板、查看打卡圈、参与打卡与活动。

### 3.2 必填字段清单与填写指引
进入 **【我的】** -> **【👤 个人资料与账号】**，依次完善以下带红星 `*` 的必填项：

| 字段名称 | 填写说明 | 隐私安全保护措施 |
| :--- | :--- | :--- |
| **真实姓名** `*` | 必须为身份证/护照上的真实实名，用于赛事保险与组委会检录。 | **AES-256 高强度加密存储**。默认以 `***` 星号遮罩，点击眼睛图标可显示。公开名册仅脱敏展示为（如：张*、李*华）。 |
| **生理性别** `*` | 选择 **男 (Male)** 或 **女 (Female)**。关系到戈赛配额考核与 Canova 生理能耗区间测算。 | 大群体分组考核公开，普通跑友可读。 |
| **出生日期** `*` | 点击日期选择器选择出生年月日（如：`1985-06-18`）。系统将自动推算实周岁与年龄组别。 | **密文分级脱敏**。公开名册绝不显示具体出生日期，仅展示年龄组别（大师组/壮年组/青年组）。 |
| **商学院项目** `*` | 下拉选择您所属的项目（如：`中文EMBA`、`台大班`、`复旦-BI（挪威）`、`奥林班`、`港大班`等）。 | 用于校友身份归属与分班积分统计。 |
| **所在班级/届别** `*` | 填写您所在的具体班级或届别代号（例如：`2022春2班`、`38期`）。 | 便于同班同学寻找班级战队。 |
| **戈壁经历** | 选择 **新戈**（首次备战）或 **老戈**（选择戈几，如戈20、戈21，以及参选组别 A组/B组/C组）。 | 辅助教练团队进行针对性训练负荷监控。 |
| **联系手机** | 建议如实填写真实可用手机号，用于突发状况或赛事通知。 | 采用密文存储，对外完全隐藏。 |
| **身份证号** | 选填。用于大型越野赛或长距离拉练统一购买意外保险。 | 默认 `***` 遮罩隐藏，非管理员普通跑友绝不可见。 |
| **参赛保障** | 选择服装尺码（S~4XL）、跑鞋尺码，勾选健康安全声明。 | 用于团队统一装备订制发放。 |

填写完毕后，务必点击页面下方的 **`💾 保存个人资料与账号设置`** 按钮！

### 3.3 审核状态流转与超期恢复
在【我的】页面顶部的大群体状态卡片中，您可以实时查看自己的认证状态：
- ⏳ **临时状态 · 余 X 天**：资料尚有缺失，卡片将明确列出“待补齐必填项”，点击 **【📝 立即前往补齐必填字段】** 可一键跳转定位。
- 📋 **待管理员核验 · 余 X 天**：您已填全所有必填项，正等待大群管理员后台核准转正。
- 🏅 **正式队员 · 已核验**：管理员已通过审核，恭喜您获得大群及全部从属跑团的**永久完全访问权限**！
- 🚫 **访问已暂停**：若超期被冻结，请勿慌张。进入【我的】->【👤 个人资料与账号】补齐缺失项目并保存，随后微信联系大群管理员（或领队）进行后台审核解冻即可瞬间恢复。

## 第四步：生理体能指标与测算

科学耐力训练的核心是**基于个体心率与摄氧量进行精准配速分区**。

1. 进入 **【我的】** -> 切换至 **【🏃 训练档案与赛事】** 标签页。
2. 找到 **【运动体能与生理指标】** 卡片：
   - **最大摄氧量 (VO2Max)**：
     - 若您已录入 5K/10K/半马/全马成绩，可点击右上角 **`⚡ 依据 PB 测算`**，系统将调用 Jack Daniels VDOT 运动学公式自动逆推您的当前摄氧量潜能。
     - 也可直接点击 **【从手表同步指标】**，自动抓取 Garmin/COROS 测算的最新 VO2Max。
   - **身体维度**：身高 (cm)、体重 (kg)。
   - **心率基准**：
     - **静息心率 (Rest HR)**：清晨静息脉搏（如：48~58 bpm）。
     - **最大心率 (Max HR)**：建议根据最大心率测试或常用经验公式设定（如：180~195 bpm）。
   - **跑龄**：坚持跑步的年限。
3. 点击底部 **`🎯 保存训练目标与生理参数`**。
4. **生成的训练价值**：系统搭载的 **Renato Canova 意大利特异性训练模型** 将根据您的体能数据，在【教练】模块自动生成您的专属 6 级配速区间（基础耐力、有氧特异、乳酸阈值配速、比赛节奏配速）与超量恢复时间窗口。

## 第五步：设立周计划、月计划与比赛目标

### 5.1 设定 2026 年度与月跑量规划
进入 **【我的】** -> **【🏃 训练档案与赛事】** -> **【个人跑量目标规划】**：
- **模式 A：全年统一均值**
  - 拖动滑块直接设定每月的目标跑量（例如：`200 km/月`）。
  - 适合平时训练节奏稳定、常年坚持匀速积累有氧底子的跑者。
- **模式 B：按月自定义（针对秋冬/春季备赛期）**
  - 点击选择“按月自定义 (备赛期进阶)”。
  - 可以在 1~12 月的网格中为重点月份输入不同的跑量目标（例如：1-3月冬训基础期 160km -> 4-6月拉练期 220km -> 7-8月夏训期 180km -> 9-10月赛前冲刺期 280km）。
  - 系统会自动汇总计算出您的 2026 全年总目标里程。

### 5.2 设定每周重点跑量目标
- 在月计划下方，找到 **【本周重点跑量目标卡】**：
  - 点击快捷胶囊选择本周挑战（`30km`、`40km`、`50km`、`60km`、`70km+`）或手动输入。
  - 点击 **【单独保存周跑量目标】** 快速生效。
  - 在微信小程序【首页】与 Web 【仪表盘】中，周进度环形图将每日动态更新，显示本周剩余目标公里数与达标预测。

### 5.3 添加比赛日程与 AI 赛事情报
- 在 **【比赛计划与倒计时】** 卡片中点击 **【➕ 添加赛事】**：
  - **比赛名称**：例如“2026 敦煌戈壁挑战赛”、“2026 上海马拉松”。
  - **比赛类型**：马拉松 (42.195km)、半程马拉松 (21.0975km)、戈壁多日赛 (121km)、越野赛 (50km/100km) 等。
  - **比赛日期**：选择开赛日期，主页将自动呈现 **天数倒计时**。
  - **目标完赛成绩**：输入心仪目标（如：`03:30:00`）。
  - **优先级等级**：
    - `A 级主赛`：年度终极大考，Canova 教练将在此周提前安排减量与碳水储备期。
    - `B 级以赛代练`：次要赛事，当作长距离节奏拉练。
    - `C 级打卡测试`：轻松参与，测试补给与装备。
  - **AI 赛事情报一键检索**：点击赛事情报按钮，AI 将联网抓取该赛事的赛道起伏、累计爬升海拔、平均气温与关门时间，辅助制定比赛日配速战术。
  - **完赛勋章与照片打卡**：完赛后可将状态更改为“已完赛”，上传赛道定妆照、挂奖牌照与完赛总结，生成专属永久戈友荣誉卡片。

## 常见问题与帮助支持 (FAQ)

### Q1：为什么提示“跑团访问权限已暂停”？
> **解答**：这说明您加入的跑团（如复旦戈闵文跑团）隶属于“复旦戈”大群，而您的大群 14 天临时访问期已到期，但个人资料中还有星号 `*` 必填项尚未完成，或管理员尚未确认。  
> **解决办法**：请进入【我的】->【👤 个人资料与账号】，检查并补齐“真实姓名、生理性别、出生日期、商学院项目、班级”，保存后联系大群管理员（或小团领队）为您在后台点击【确认转正】即可即刻解冻。

### Q2：佳明手表跑步后，数据没有同步过来怎么办？
> **解答**：
> 1. 请检查 Garmin Connect 手机 App 是否已将手表数据蓝牙同步到佳明云端。
> 2. 检查【我的】->【运动手表直连】中的服务器分区是否选对（国内行货选“中国区”，水货/海淘选“国际区”）。
> 3. 若修改了佳明密码，请在页面点击“重新绑定佳明账号”。

### Q3：填写身份证与真实姓名安全吗？会被其他人看到吗？
> **解答**：
> 绝对安全！系统在底层采用银行业标准的 **AES-256-GCM 工业级加密算法** 存储您的姓名、证件号、手机号和出生日期。在公开跑团队伍名册中，**普通跑友只能看到脱敏姓名（如：李*华）与年龄组别（如：大师组），普通成员绝无权限查阅您的任何敏感明文**。此外，页面底部提供了 **“🧹 一键清除所有个人隐私数据”** 通道，您随时可以彻底抹除个人隐私底账。
